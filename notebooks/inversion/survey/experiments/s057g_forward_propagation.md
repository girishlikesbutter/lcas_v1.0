## TL;DR

Per-q_a multi-Δ centroid (s057f) failed structurally because finite-diff at small geodesic distance is geometrically noisy. This pivots to **forward-propagation discrimination**: for each candidate (q_a, ω) — generated by single-pair finite-diff at Δ_gen=15, filtered by ±25% |ω|-prior — propagate q_a forward via const-ω quaternion exponential to multiple validator epochs, check whether the propagated q lands within HIT_THRESHOLD_DEG=5° of any survivor in C_{t_v}. Score per candidate = Σ_v weight_v × indicator(hit), weight = log(100k/|C_v|). **Result: discrimination ratio 4400× over null expectation**. Scores range [22, 243] vs null E[score] = 0.04. Truth candidate scores 178 (44% of max possible 406), ranks 55/548 (top 10%). Top candidates dominated by body-twin q_a's and other geometrically-valid alternates.

## What

The first architecture variant in the s057 series that produces strong, statistically meaningful discrimination. Hypothesis: the per-pair finite-diff noise can be tolerated if we VALIDATE candidates by forward-propagation against MULTIPLE validators with weighted scoring, rather than by per-pair angular distance to truth.

## How

1. **Smoke test** const-ω propagation: propagate q_truth(t_a) forward using truth-ω over Δ ∈ {1,2,3,5,7,10,15,20,30,50,80} epochs; measure deviation from cached q_truth(t_a+Δ). Result: `Δ=10 → 0.46° err, Δ=50 → 11.30° err, Δ=80 → 25.57° err`. Const-ω reliable to Δ=50 (~6 min) — much wider than expected for seed 89's near-separatrix dynamics.
2. **Validators**: all epochs in window [t_a−50, t_a+50] excluding t_a; for each, weight = log(100k/|C_v|). 100 validators total, |C_v| range [45, 5883], total weight = 406.15.
3. **Candidate generation** at Δ_gen=15 (best per-pair accuracy in s057d): all 44×450=19800 pairs of finite-diff ω, filter at ±25% |ω|-prior → 548 candidates.
4. **Scoring**: for each candidate, propagate q_a forward to each t_v using its ω, find min angular distance to any survivor in C_{t_v}, hit if < 5°, accumulate weighted hits. Vectorised over all 548 candidates per validator.
5. **Diagnostic**: track candidate closest to (truth_q_a, truth_ω) — by `argmin(qa_dist + om_dist)` — as the "truth candidate". Where does it rank?

Wall: ~5s.

## Why this matters

- **First architecture in the s057 series with strong, statistically decisive discrimination**. 4400× over null is qualitatively different from s050b cascade-validation's <1.5× failure; from per-q_a centroid's structural inversion (s057f).
- **Truth IS in the top 10% of candidates** — the architecture correctly identifies (q_a, ω) consistency as a strong constraint.
- **But truth is NOT #1** — top candidates are body-twins + multi-solution alternates that ALSO satisfy local forward-propagation consistency. This is the multi-solution philosophy made visible.
- **Operational role**: this architecture is a **seed generator**, not a unique inversion answer. Reduces 100k Sobol grid → ~325 clusters (post-canonicalisation in s057h) of plausible (q_a, ω). Each requires LM polish to refine → final ρ-band classification.
