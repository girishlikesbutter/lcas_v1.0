## 2026-01-21 - US-003
- What was implemented: Implemented propagate_euler() for tumbling attitude dynamics using coupled Euler equations + quaternion kinematics
- Files changed:
  - src/dynamics/attitude_propagator.py - added scipy.integrate import, implemented propagate_euler() function
- **Learnings for future iterations:**
  - Euler's equations (torque-free): I @ omega_dot = -omega x (I @ omega), so omega_dot = I_inv @ (-omega x (I @ omega))
  - Quaternion kinematics: q_dot = 0.5 * q * [0, omega_x, omega_y, omega_z]
  - Use DOP853 solver (8th order) with tight tolerances (rtol=1e-10, atol=1e-12) for good conservation
  - Renormalize quaternion both inside dynamics() and after solution extraction to prevent drift
  - Precompute I_inv outside the dynamics function for efficiency
  - Verify conservation laws: angular momentum magnitude and kinetic energy should stay constant
  - Reuse existing _quaternion_multiply() helper for q_dot calculation

## 2026-01-21 - US-007
- What was implemented: Added compute_component_inertia(mesh, mass) function to compute inertia tensor for a single STL component
- Files changed:
  - src/computation/inertia_calculator.py - added compute_component_inertia() function
  - src/computation/__init__.py - added export for compute_component_inertia
- **Learnings for future iterations:**
  - Inertia tensor calculation uses volume integrals over tetrahedra formed by each face and origin
  - Formula for integral(x^2) over tetrahedron: V * (a_x^2 + b_x^2 + c_x^2 + a_x*b_x + a_x*c_x + b_x*c_x) / 10
  - Center of mass is computed as volume-weighted centroid, where each tetrahedron centroid is (v0 + v1 + v2) / 4
  - Use inverse parallel axis theorem to translate inertia from origin to CoM: I_cm = I_origin - m*(d²I - outer(d,d))
  - Inertia tensor sign convention: diagonal positive, off-diagonal negative (I_xy = -integral(xy dm))
