## Codebase Patterns
- Notebooks use Jupytext percent format with `formats: ipynb,py:percent` header
- Setup pattern: PROJECT_ROOT detection, sys.path insert, os.chdir, then imports
- ObjectiveFunction takes `compute_shadows_flag` (True=hi-fi with ray tracing, False=lo-fi with all-lit approximation)
- True attitude params stored as 6-element vector: [axis_angle_x, axis_angle_y, axis_angle_z, omega_x, omega_y, omega_z]
- CountedObjective wrapper normalizes axis-angle via quaternion round-trip before evaluation
- Parameter bounds: axis-angle [-pi, pi], omega [-30 deg/s, 30 deg/s] in radians
- Success criteria: omega error < 0.1 deg/s AND RMS residual < 2x noise_sigma
- SPICE Observer ID for ground station: 399999
- Fixed articulation: solar panels 0 deg, antenna dishes 15 deg
- Inertia tensor computed with specific component masses (Bus: 1532, SP: 170 each, AD: 50 each)
