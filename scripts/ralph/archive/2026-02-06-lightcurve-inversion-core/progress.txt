## 2026-01-21 - US-018
- What was implemented: Implemented compute_fisher_uncertainty() function for quick uncertainty estimation using Fisher Information Matrix
- Files changed:
  - src/inversion/uncertainty.py - added _compute_hessian() helper and implemented compute_fisher_uncertainty()
- **Learnings for future iterations:**
  - Fisher Information Matrix uses Hessian of chi-squared at the optimum
  - For chi-squared objectives: covariance = 2 * Hessian^{-1} (factor of 2 from chi-squared formula)
  - Central finite differences for Hessian: diagonal uses (f(x+h) - 2*f(x) + f(x-h)) / h^2
  - Off-diagonal uses 4-point formula: (f_pp - f_pm - f_mp + f_mm) / (4*h^2)
  - Handle non-positive-definite Hessian by regularization: add |min_eigenvalue| + epsilon to diagonal
  - Check eigenvalues with np.linalg.eigvalsh() for symmetric matrices (faster than eig)
  - Return infinite uncertainties if Hessian inversion completely fails
